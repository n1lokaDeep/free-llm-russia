# free-llm-russia

**Бесплатные LLM и нейросети для России: что работает без VPN, что без карты, что без того и другого.**

Все существующие списки «free LLM APIs» написаны для Запада. В них не отмечено
главное: **можно ли вообще достучаться до сервиса из РФ** и **примут ли российскую карту**.
Этот список закрывает именно этот пробел.

Проверено на живой машине в РФ, октябрь 2026.

## Главная проблема

Три разных препятствия, которые постоянно путают:

| Препятствие | Как выглядит | Чем лечится |
|---|---|---|
| **Геоблокировка по IP** | `403 Access denied by security policy` | прокси/VPN |
| **Требуется зарубежная карта** | регистрация не проходит | виртуальная карта или сервис без карты |
| **Требуется VPN для самого сайта** | страница не открывается | только для браузера, API может работать |

**Важно:** API и веб-сайт часто блокируются по-разному. Сайт `openrouter.ai`
может не открываться в браузере, но API при этом доступен с правильного IP.
И наоборот.

## Что работает без VPN

Сервисы, доступные с российского IP. Проверяйте актуальность: провайдеры меняют
политику без предупреждения.

| Сервис | Нужна карта | Лимит | Модели |
|---|---|---|---|
| **Z AI (Zhipu)** — `open.bigmodel.cn` | нет | 1 параллельный запрос | GLM-4.7-Flash, GLM-4.6V-Flash |
| **ModelScope** — `modelscope.cn` | нет, но нужна верификация | 2000 запросов/день | Qwen3.5 |
| **SiliconFlow** — `api.siliconflow.cn` | нет, нужна верификация | 1000 RPM | Qwen3-8B |
| **Mistral** — `api.mistral.ai` | нет | ~$10/мес кредитов | Mistral Medium 3.5 |
| **OVHcloud AI** — `oai.endpoints.kepler.ai.cloud.ovh.net` | **не нужен даже ключ** | 2 RPM на модель | Qwen3.5-397B, gpt-oss-120b |

**Про китайские сервисы:** Z AI принимает зарубежные номера телефонов и не требует
верификации для chat API. ModelScope и SiliconFlow требуют верификацию по китайским
документам.

**OVHcloud — самый простой вариант для теста:** ключ не нужен вообще, но 2 запроса
в минуту.

## Что работает только через прокси

Доступны из РФ **только** с зарубежным IP. Ключ при этом получить можно.

| Сервис | Нужна карта | Лимит | Примечание |
|---|---|---|---|
| **OpenRouter** — `openrouter.ai/api/v1` | нет | **50 запросов/день** на модель | 17 бесплатных моделей `:free` |
| **Groq** — `api.groq.com/openai/v1` | нет | 30 RPM, 1000 RPD | очень быстрый |
| **Cloudflare Workers AI** | нет | 10 000 нейронов/день | 60+ моделей |
| **Google Gemini** — `generativelanguage.googleapis.com` | нет | 15 RPM, 1500 RPD | Flash-модели |
| **NVIDIA NIM** — `integrate.api.nvidia.com/v1` | нужна регистрация | 40 RPM, 10 000 RPD | 100+ моделей |
| **Ollama Cloud** — `ollama.com/api` | нет | не опубликованы | 16 cloud-моделей |
| **Kilo Code** — `api.kilo.ai/api/gateway` | **не нужен даже ключ** | 200 запросов/час | бесплатный пул моделей |
| **LLM7.io** — `api.llm7.io/v1` | нет | 60 RPM, 250/час | анонимный доступ |

### OpenRouter: главное про лимиты

- **50 запросов в день на каждую бесплатную модель.** Не общий лимит — на модель.
- Покупка кредитов на $10+ разово поднимает лимит до **1000 запросов/день**.
- Есть авто-роутер `openrouter/free` — сам выбирает доступную бесплатную модель.
- Бесплатные провайдеры **могут логировать промпты** для обучения.

## Что НЕ работает из РФ

| Сервис | Причина |
|---|---|
| **ChatGPT / OpenAI API** | полная блокировка по региону |
| **Claude / Anthropic API** | полная блокировка по региону |
| **Cloudflare WARP** | эндпоинты `188.114.97.170:894` и др. заблокированы провайдером |

### Про WARP отдельно

Распространённый совет «поставь WARP, он бесплатный» **не работает в РФ**:

```
188.114.97.170:894   →  заблокирован
162.159.192.1:894    →  заблокирован
api.cloudflareclient.com  →  timeout
```

Регистрация в WARP не проходит, потому что серверы регистрации недоступны.
Профили WARP в клиентах (Hiddify и подобных) падают с ошибкой:

```
error patching outbound: netip.ParsePrefix("/24"): ParseAddr(""): unable to parse IP
```

Это следствие того, что WARP-аккаунт не зарегистрирован.

**Отдельная ирония:** WARP выдаёт адрес Cloudflare, а блокирует вас тоже Cloudflare.
Даже если бы он подключился, результат непредсказуем.

## Почему Cloudflare отбивает запросы

Если вы видите такое:

```
HTTP 403 Forbidden
{"success": false, "error": "Access denied by security policy."}
CF-RAY: a4d9c891184604fe-HKG
```

**Это не ваша ошибка и не проблема ключа.** Cloudflare блокирует по репутации IP
**до того**, как запрос дойдёт до сервиса.

Как это отличить от проблем с ключом:

| Симптом | Диагноз |
|---|---|
| `403` + `Access denied by security policy` | блок по IP. Ключ ни при чём |
| `401` + `Authentication Fails` | ключ неверный или не от того сервиса |
| `404` + `Not found for account` | модель недоступна вашему аккаунту |
| `429` | лимит исчерпан |

**Проверка одной командой** — отличает блокировку от проблемы с ключом:

```powershell
Invoke-RestMethod https://api.ipify.org
```

Если IP российский, а сервис даёт `security policy` — нужен прокси.

**Важно:** смена ключа не помогает. Мы это проверили: два разных ключа дали
одинаковый `403` с одного IP.

## Как поднять прокси

Полноценный VPN требует прав администратора (создание TUN-адаптера). Если прав
нет — работает локальный прокси: он заворачивает только нужные приложения.

### В чём разница

| | VPN (TUN) | Локальный прокси |
|---|---|---|
| Заворачивает | весь компьютер | только указанные программы |
| Нужен админ | да | **нет** |
| Подходит для | браузер, игры, всё | конкретный инструмент (OpenCode и т.п.) |

### Способ: sing-box + публичные конфиги

Скрипты в папке [`scripts/`](scripts/) автоматизируют это.

**Где брать конфиги.** Публичные репозитории с `vless://` ссылками, например
`Epodonios/v2ray-configs`. Реальность: **из 5681 конфига живыми оказались 2.**
Поэтому нужен автоматический отбор — он в скрипте.

**Ключевой момент:** TCP-порт может быть открыт, но рукопожатие Reality не
проходить. Проверять надо реальным запросом, а не `ping` или `Test-NetConnection`.

## Скрипты

См. [`scripts/`](scripts/):

| Файл | Назначение |
|---|---|
| `start-proxy.ps1` | поднять прокси на `127.0.0.1:18888` |
| `proxy.ps1` | управление: `start` / `stop` / `restart` / `status` |
| `check-configs.py` | отобрать живые конфиги из списка |
| `launch-opencode.ps1` | пример: запуск приложения через прокси |

### Быстрый старт

```powershell
# 1. Поднять прокси
powershell -File scripts\start-proxy.ps1

# 2. Проверить
powershell -File scripts\proxy.ps1 status

# 3. Остановить
powershell -File scripts\proxy.ps1 stop
```

### Важно: не прописывайте прокси глобально

**Не делайте этого:**

```powershell
# ТАК НЕ НАДО - сломает другие программы
[Environment]::SetEnvironmentVariable('HTTPS_PROXY','http://127.0.0.1:18888','User')
```

Программы, которые не должны идти через прокси (игры, лаунчеры), начнут через
него ходить и падать с `ConnectFail`. Прокси нужно задавать **только внутри
запускаемой программы**:

```powershell
$env:HTTPS_PROXY = 'http://127.0.0.1:18888'
& myapp.exe
```

Это проверено на практике: глобальные переменные ломали Roblox.

## Частые ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `403 Access denied by security policy` | блок по IP | прокси |
| `401 Authentication Fails` | ключ не от того сервиса | проверить `baseURL` |
| `ConnectFail` после настройки прокси | прокси прописан глобально | убрать глобальные переменные |
| Прокси запущен, но модели молчат | приложение не увидело прокси | задать переменные внутри процесса |
| Конфиг «мёртвый» | сервер отключён | отобрать живые скриптом |
| `netip.ParsePrefix("/24")` | WARP не зарегистрирован | не использовать WARP в РФ |
